# Junction expression of interest: RFEOI 2026-NILN-01

Interactive companion to Junction's submission to Indigenous Tourism BC for the Northern Indigenous Lodge Network training program design.

Live site: https://itbc-proposal.netlify.app

## Files

- `index.html` is the interactive page. Fonts and wordmarks are embedded, so it is one self-contained file.
- `Junction-RFEOI-2026-NILN-01.pdf` is the signed, searchable submission. The page's download buttons point to this file name, so keep it unchanged.

## Deploy

1. Create a GitHub repository and upload both files to the root.
2. In Netlify, add a new site from that repository. No build command. Publish directory is the root.
3. Set the site name to `itbc-proposal`.
4. Open the live site and test the "Download the PDF submission" button.
